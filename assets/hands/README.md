Reference handshape photos for learn cards and hints.

Name them by letter: `A.jpg`, `B.jpg`, ... `Y.jpg` (no J or Z). Any letter
without a photo just shows the tip text.

Take your own photos (or get permission) - don't use images from the web
unless their license allows it. Plain background, hand filling most of the
frame, shot from the viewer's side, the way the player will copy it.
